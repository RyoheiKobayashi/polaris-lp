01

LLM

Large Language Model

人間が書いた大量のテキストデータを学習し、自然な文章を生成できるAIの仕組み。ChatGPT・Gemini・Claudeはすべてこの「LLM」をベースに作られています。

02

AIモデル

AI Model

AIの「頭脳」にあたる部分。同じサービス（例: ChatGPT）でも、搭載されるモデルによって賢さや速度が異なります。「Gemini 2.5 Pro」「GPT-4o」などの名前がついています。

Read →
03

ナレッジカットオフ

Knowledge Cutoff

AIモデルが学習したデータの最終日のこと。それ以降の出来事をAIは知りません。だからこそ自分の最新情報をナレッジとして渡す必要があります。

Read →
04

ハルシネーション

Hallucination

AIが事実と異なる情報をもっともらしく生成してしまう現象。「AIの幻覚」とも呼ばれます。発信や業務利用ではファクトチェックが必須です。

Read →
05

トークン

Token

AIが文章を処理する際の最小単位。日本語は1文字が1〜3トークン程度。入力と出力の合計トークン数に上限があり、一度に扱える情報量の限界を決めます。

Read →
06

AI（人工知能）

Artificial Intelligence

人間の知的な作業（文章作成・分析・判断など）をコンピュータに行わせる技術の総称。ChatGPT・Gemini・Claudeなどの生成AIもこれに含まれます。

Read →
07

生成AI

Generative AI

テキスト・画像・動画など新しいコンテンツを「生成」できるタイプのAI。ChatGPT・Gemini・Claudeはすべて生成AIに分類されます。

Read →
08

コンテキスト
ウィンドウ

Context Window

AIが一度の会話で読み込めるトークン数の上限。この枠に収まる範囲でしかAIは情報を参照できません。長文のナレッジは必要な情報に絞って渡すのが重要です。

Read →
09

マルチモーダル

Multimodal

テキストだけでなく、画像・音声・動画など複数の形式のデータを同時に扱えるAIの能力。「この画像を説明して」と頼めるのはマルチモーダルのおかげです。

Read →
10

RAG

Retrieval-Augmented Generation

AIが回答を生成する前に、外部のデータから関連情報を検索して取り込む仕組み。AIの知識不足を自分のデータで補う技術です。

Read →
11

メモリ

Memory

AIが過去の会話内容や好みを記憶し、次の会話に反映する機能。ChatGPTやGeminiに搭載。ただし精度は完全ではないため、重要な指示はナレッジで明示的に渡すのが確実。
