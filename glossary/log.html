ログ

システムが残す作業記録

09:12 OK user login 09:13 OK save data 09:15 WARN slow query 09:16 OK recovered 09:18 OK user logout

ログってそもそも何？

システムが「いつ・何をしたか」を淡々と記録するファイル。エラーが起きた時、ここを見れば原因がわかります。平時は何も起きなくても、何かトラブったら真っ先に開くのがログ。AIに動かしてもらったスクリプトが失敗した時、ログを見せて原因を調べてもらうのが解決の第一歩です。

身近な例えで理解する

例① 作業日報

「今日は何を、何時から何時まで、どれくらい進めたか」を書く日報。後から振り返って検証できる記録です。ログもこの日報と同じで、システムが自分の作業を淡々と記録しています。

例② 車のドラレコ映像

事故が起きた時、ドラレコを巻き戻せば原因がわかる。普段は撮りっぱなしで気にしないけど、いざという時に命綱になる。ログもこのドラレコと同じ役割です。

📝
まとめ

ログはシステムの作業記録。エラーが出た時にまず読む場所なので、「ログを見せて」と言われたら意味がわかる状態にしておきたいです。
