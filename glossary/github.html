GitHub / GitHub Pages

GitHub

コード保管庫 + 無料Web公開

GitHub / GitHub Pagesってそもそも何？

GitHubはコードのバージョン管理と共有ができるプラットフォームです。「いつ・誰が・何を変更したか」を記録して、複数人で協力して開発できる。さらにGitHub Pagesを使えば、HTMLファイルをそのまま無料でWebサイトとして公開できる。このAI用語集自体もGitHub上で管理されています。

身近な例えで理解する

例① 共有タイムトラベル機能付きDropbox

ファイルの履歴が全部残って、「昨日の状態に戻したい」が自由にできる。しかも誰がどこを変えたか全部見える。編集・改善の安心感が変わります。

例② LPの無料サーバー

GitHub Pagesを使えば、サーバーを借りずにHTMLファイルが公開できる。AIに作らせたLPをそのままWebに出す、最短ルートです。

まとめ

GitHubは、コードの博物館 + 自動公開サーバー。AIが作ったツール・LPを世に出すときの標準インフラです。
